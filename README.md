## 云服务器价格不是"标准价"，是配置组合价

大厂广告里那个"99元/年"，和你在选购页点进去看到的最终价格，经常是两回事。原因是云服务器的报价由好几块拼起来，其中只有第一块被写进标题：

1. **计算套餐**：CPU 核数 + 内存，这是最直观的一块，也是各家拿来对比的基准。
2. **带宽**：上行和下行是两个数字，独享还是共享又不一样。10M 和 100M 的差价可能比 CPU 从 2 核升到 4 核还大。
3. **流量计费方式**：不限流量，还是限流量但带宽给得高。这两种模式的成本结构完全不同。
4. **磁盘**：套餐自带多少 G，扩容单价多少。数据库类应用对这块很敏感。
5. **IP 与防御**：是不是独立 IPv4，要不要高防 IP。国内部分线路的独立 IP 是额外收费的。
6. **计费周期**：月付、季付、年付的单价差别，通常能拉开 10%–30%。

把这六项分开看，"云服务器价格"这个问题就不再是玄学，而是一张可以自己算的账单。

## 按场景选：多花的钱该花在哪

**个人博客 / 学 Linux**
1核1G 或 2核2G 够用。真正影响访问体验的是线路，不是核数。面向国内读者又没有备案域名，香港入门版或标配版是常见选择。

**小程序后端 / 小型接口服务**
2核4G 起步更稳妥。数据库和 Web 服务挤在同一台机器上时，2G 内存很容易被拖到 swap，价格上多花 10 元左右就能避开这个坑。

**Minecraft / 游戏开服**
这类场景吃的是单核主频，不是核数。雨云的游戏云线路上有 i9-14900K、Ryzen 7950X 这类高主频机型，专门为这个需求准备。但要留意宿迁部分机型走的是共享 NAT 模式，没法直接对外开 80/443 端口，做网站不合适，开服和内网穿透倒是正合适。

**跨境业务 / 免备案站点**
香港三网直连和洛杉矶双线是主力。香港延迟低，洛杉矶带宽大。如果目标是外贸站或者需要海外 IP 的服务，盯线路线路质量比盯价格更有意义。

**怕被攻击**
宁波、宿迁、十堰这几条国内线路都带 100G 以上的高防，价格比普通线路高，但省掉的是被打挂之后重搭环境的时间。

## 下单前值得确认的几件事

- **退款政策**：7 天无理由退款，每个账号限 3 次。试用期别浪费。
- **NAT 与独立 IP**：不是所有套餐都自带独立公网 IPv4。宿迁、十堰等线路如果要建站，独立 IP 是额外支出，算总价时别忘了。
- **流量计费方向**：流量型产品上下行流量都计入，别按单向估算。
- **磁盘扩容单价**：系统盘写死 30G 的套餐，后期靠扩容顶上去，单价会体现在账单里。
- **系统支持范围**：支持 Windows 和 Linux，macOS 只有少数区域可选，买之前确认一下。
- **弹性升级**：支持按天补差价升配，前期买小一点、后期往上调，比一步到位更省钱。

## 几个高频问题

**月付和年付哪个划算？**
单纯看单价，年付 7 折最低。但如果项目还在验证期，先按月付跑一两个月，确认负载和线路都合适再转年付，风险更小。

**为什么有些套餐不参与年付 7 折？**
不同机房和机型有各自的折扣规则，个别区域不参与长付折扣。选购页上会直接标注，不用猜。

**"不限流量"和"流量叠加型"怎么选？**
流量曲线平稳、又需要大带宽的业务，选不限流量；流量不大但要低延迟、又要控制月付金额的，选流量叠加型更划算，用不完的流量还能结转。

**能不能先试后买？**
可以。1 元试用 1 天，每款机型限一次。搭配 7 天无理由退款，试错成本基本能压到很低。
